# Carnicería Asensio · Asensio Harategia

Web de Carnicería Asensio, carnicería de barrio en el Alde Zaharra de Donostia.

🔗 **Web:** https://carniceria-asensio.netlify.app

La hice para el negocio, para que los clientes puedan ver los productos, encontrar la tienda y hacer pedidos desde el móvil.

## Qué hace
- **Bilingüe:** euskera y castellano, con selector de idioma.
- **Pedidos por WhatsApp:** el cliente rellena un formulario (producto, cantidad, tipo de corte, día, hora, recogida o envío) y la web le deja el mensaje de WhatsApp preparado para enviar.
- Productos principales, establecimientos a los que suministra, opiniones de Google y enlace para dejar una reseña.
- Ubicación con enlace a Google Maps, horario y botón para llamar.
- Páginas de aviso legal, privacidad y cookies.
- Responsive: pensada para usarse sobre todo desde el móvil.

## Con qué está hecha
HTML, CSS y JavaScript, sin frameworks. Publicada en Netlify.

## Estructura
- `index.html`: página principal
- `styles.css`: estilos
- `script.js`: idioma y formulario de pedidos por WhatsApp
- `aviso-legal.html`, `privacidad.html`, `cookies.html`: páginas legales
- `img/`: imágenes
